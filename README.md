# 🚀 Paidi Chanukya - Portfolio Website

A modern, high-performance developer portfolio built with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Framer Motion**. Features a sleek dark theme with vibrant orange accents (`#ff5500`), smooth animations, interactive project modals, responsive design, and light/dark theme switching.

---

## ✨ Features

- **⚡ Modern Dark Aesthetic**: Styled with custom radial glowing halos, dark charcoal cards, glassmorphism elements, and glowing orange accents.
- **🌗 Light & Dark Theme Support**: Seamless theme switcher using custom CSS variables and persistent localStorage state.
- **📄 Downloadable PDF Resume**: Integrated PDF resume (`public/resume.pdf`) downloadable directly from the header and about section.
- **💻 Interactive Projects & Modals**: Comprehensive project showcase featuring filter tags, modal detail previews, and live demo links.
- **🎓 Academic Timeline & Certifications**: Structured education history timeline and verified credential badges.
- **🎯 Dynamic Custom Cursor & Scroll Progress**: Smooth cursor animations and reading progress bar for enhanced UX.
- **📱 Fully Responsive**: Optimized across desktop, tablet, and mobile breakpoints.

---

## 🛠️ Tech Stack

- **Core**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Custom CSS Variables
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Build Tool**: Vite

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/chanukyapaidi/PaidiChanukya.git
cd PaidiChanukya
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the development server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production

```bash
npm run build
```
